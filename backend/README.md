# NoteShare Backend

This folder will contain the backend code for your NoteShare app (Node.js, Express, PostgreSQL, Prisma, JWT, Google OAuth, PDF upload, etc).

All backend code and configuration will be placed here.

---

Next steps will include:
- Initializing a Node.js project
- Setting up Prisma and PostgreSQL connection
- Creating REST API endpoints
- Adding authentication and file upload logic
- Providing a .env.example file

You can run all backend commands from this folder.
